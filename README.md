# EMPLOYEE-ATTENDANCE-TRACKER-DASHBOARD

📌 Project Overview
This project is an interactive Employee Attendance Tracker Dashboard created in Microsoft Excel. The dashboard helps analyze employee attendance patterns, absenteeism trends, punctuality, and department-wise performance using data visualization techniques.

📊 Features
•	Most Punctual Employees Analysis
•	Most Punctual Departments
•	Daily Attendance Overview
•	Day with Most Absent Employees
•	Department-wise Absenteeism Analysis
•	Monthly Attendance Trend
•	Interactive Slicers for Filtering

🛠 Tools & Techniques Used
•	Microsoft Excel
•	Pivot Tables
•	Pivot Charts
•	Slicers
•	Data Cleaning
•	Dashboard Design

📈 Insights Generated
•	Identified departments with the highest absenteeism.
•	Analyzed attendance trends over time.
•	Tracked punctual employee performance.
•	Visualized daily and monthly attendance behavior.

🎯 Purpose
The goal of this project was to strengthen Excel data analysis and dashboarding skills by working on a real-world HR analytics scenario.
